🍎 苹果 CMS V10 API（主推）

严格对齐 /api.php/provide/vod 规范（hongniuzy2 / bfzy / dyttzy 三家标准）。任意支持苹果 CMS V10 的资源采集器、TVBox、CMS 前端可直接消费。

端点

参数说明
GET /api/appcms精简列表（默认，每项 8 字段）
GET /api/appcms?ac=detail&ids=<vod_id>详情模式（每项 83 字段）
GET /api/appcms?wd=<关键字>按名称 / 简介 / 分类搜索
GET /api/appcms?type_id=<id>按分类过滤（class_id 等价别名）
GET /api/appcms?page=<n>&limit=<n>分页（limit 上限 100）

顶层响应结构

{
  "code": 1,
  "msg": "数据列表",          // 详情模式返回 "数据详情"
  "page": 1, "pagecount": 1, "limit": 20, "total": 3,
  "list": [ /* 见下 */ ],
  "class": [ { "type_id": 2, "type_name": "连续剧" }, ... ]   // 始终附带
}

分隔符规范

字段分隔符示例
vod_play_from（列表）,BBA,bytedance,youku
vod_play_from（详情）$$$BBA$$$bytedance$$$youku
vod_play_url 源间$$$src1_urls$$$src2_urls
vod_play_url 源内集#第01集$URL#第02集$URL
vod_play_url 每集name$url第01集$https://域名/api/play?...

cURL 示例

# 全部列表
curl "https://$HOST/api/appcms"

# 单片详情
curl "https://$HOST/api/appcms?ac=detail&ids=305048"

# 按关键字搜索
curl "https://$HOST/api/appcms?wd=法医"

# 按分类筛选
curl "https://$HOST/api/appcms?type_id=2"     # 连续剧
curl "https://$HOST/api/appcms?class_id=30"   # 短剧

📺 播放器使用（直连播放）

苹果 CMS V10 输出的 vod_play_url 里的每集 URL 就是下面这个格式 — 播放器（m3u8/MPV/VLC/TVBox）可直接播放。

基本格式

GET /api/play?movie=<vod_id>&source=<code>&episode=<n>[&raw=1][&refresh=1]

示例

# 默认：m3u8 自动重写分片走 /api/seg 代理（跨域播放器友好）
curl "https://$HOST/api/play?movie=vod-19067&source=BBA&episode=1"

# raw=1：302 到原始直链（省函数流量；需播放器 UA 设为 dart）
curl -L "https://$HOST/api/play?movie=vod-19067&source=BBA&episode=1&raw=1"

# refresh=1：强制跳过缓存重新解析
curl "https://$HOST/api/play?movie=vod-19067&source=BBA&episode=1&refresh=1"

参数说明

参数必需说明
movie是片目 id，形如 vod-305048
source是播放源代码，如 BBA / bytedance / youku
episode是集号（数字），如 1 / 12
raw否1 = 302 到直链（不经函数代理）
refresh否1 = 跳过缓存，强制重新解析

常见播放器配置

MPV / VLC — 直接播放 m3u8 
mpv "https://$HOST/api/play?movie=vod-19067&source=BBA&episode=1"
vlc  "https://$HOST/api/play?movie=vod-19067&source=BBA&episode=1"
TVBox / 播放器（走 raw=1 直链，需设置 UA） 
# 需把播放器 User-Agent 设为：Dart/3.13 (dart:io)
"https://$HOST/api/play?movie=vod-19067&source=BBA&episode=1&raw=1"

🔧 运维端点

方法路径说明
GET/health健康检查（版本 / 状态 / 片目数 / 缓存大小）
GET/api/catalog片库列表（内部结构）
GET/api/search?q=<keyword>按关键字搜索
GET/api/token?movie=&source=&episode=调试：查看原始 token
GET/api/store存储自检（Turso / KV 状态）
GET/api/seg?url=<base64>媒体代理（Range 透传 + dart UA）
POST/api/add-movie导入 maomao.php 详情 dump（免重部署）
DELETE/api/delete/<id>删除片目
POST/api/cache/clear清空解析缓存

📥 导入新片目

把从 App 抓到的详情 JSON（data.vod_info + data.vod_url_with_player 结构）POST 到接口即可，无需重新部署。

curl -X POST "https://$HOST/api/add-movie" \
  -H "Content-Type: application/json" \
  --data-binary @detail.json

配置了 Turso 后，新片目会直接落库到数据库（跨实例、跨重部署持久化）。
