API 端点

方法路径说明
GET/health存活检查
GET/api/catalog列出所有片目
GET/api/movie/{id}片目详情
GET/api/play?movie=&source=&episode=[&redirect=1]中转核心：token → 新鲜直链
GET/api/token?movie=&source=&episode?调试：查看原始 token
POST/api/add-movie导入 maomao.php 详情 dump
DELETE/api/movie/{id}删除片目

快速示例

# JSON 返回
curl "https://YOUR_HOST/api/play?movie=vod-12345&source=BBA&episode=1"

# 302 直链
curl -L "https://YOUR_HOST/api/play?movie=vod-12345&source=BBA&episode=1&redirect=1"

导入片目

curl -X POST "https://YOUR_HOST/api/add-movie" \
  -H "Content-Type: application/json" \
  --data-binary @detail.json
